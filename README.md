# TP 4.2 & 5 - Catalogue de Produits (Mini Boutique)

Ce projet est une première application statique développée avec **React** et **Vite**. L'objectif principal était d'apprendre à découper une interface utilisateur en plusieurs composants réutilisables et à leur transmettre des données.

---

## Guide de Lancement Rapide

Suivre ces étapes simples pour lancer le projet sur une machine locale :

1. **Ouvrir le terminal :** Se placer à la racine du dossier du projet (là où se trouve le fichier `package.json`).
2. **Installer les dépendances :** Installer tous les paquets nécessaires avec la commande suivante :
   ```bash
   npm install
3. **Lancer le projet** : Démarrer le serveur de développement de Vite :
   ```bash
   npm run dev
4. Ouvrir l'application : Cliquer sur le lien généré dans le terminal (généralement http://localhost:5173) pour voir la boutique dans le navigateur.
