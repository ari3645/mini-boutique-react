# TP 4.2 - Catalogue de Produits (Mini Boutique)

Ce projet est une première application statique développée avec **React** et **Vite**. L'objectif principal était d'apprendre à découper une interface utilisateur en plusieurs composants réutilisables et à leur transmettre des données.

---

## 🚀 Guide de Lancement Rapide

Suis ces étapes simples pour lancer le projet sur ta machine :

1. **Ouvrir le terminal :** Place-toi à la racine du dossier de ton projet (là où se trouve le fichier `package.json`).
2. **Installer les dépendances :** Installe tous les paquets nécessaires avec la commande suivante :
   ```bash
   npm install
3. **Lancer le projet** : Démarre le serveur de développement de Vite :
   ```bash
   npm run dev
4. Ouvrir l'application : Clique sur le lien généré dans ton terminal (généralement http://localhost:5173) pour voir ta boutique dans ton navigateur.
